# Payment & Expense Management System

A full-stack financial application providing simulated digital wallet management, peer-to-peer fund transfers, expense tracking, and cashflow analytics.

## Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Python Flask REST API
- Database: SQLite (default) and MySQL

## Core Capabilities
- User registration and authentication
- Simulated wallet balance top-ups
- Peer-to-peer transfers with balance validation
- Transaction ledger and categorization
- Monthly expense breakdown and cashflow metrics
- CSV statement export

## Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+ (optional, for React development server)

### Running Backend
```bash
python backend/app.py
```
Open `http://127.0.0.1:5000` in your browser to access the dashboard.
